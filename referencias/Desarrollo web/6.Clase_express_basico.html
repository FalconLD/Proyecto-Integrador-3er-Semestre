Clase: Express.js Básico

Material de apoyo para estudiantes — desarrollo web.

Objetivo

Aprender a crear servidores web con Express.js, entender qué son las rutas, cómo manejar peticiones HTTP, trabajar con middleware, y crear tu primera API básica. Express.js es el framework más popular para crear aplicaciones backend con Node.js.

🚀 ¿Qué es Express.js?

Express.js es un framework web minimalista y flexible para Node.js que proporciona un conjunto robusto de características para desarrollar aplicaciones web y APIs.

Características principales

  • Minimalista: Framework ligero sin muchas abstracciones
  • Flexible: Puedes agregar solo lo que necesitas
  • Rápido: Optimizado para alto rendimiento
  • Popular: El framework más usado en Node.js
  • Middleware: Sistema potente de middleware para manejar peticiones
  • Rutas: Sistema de enrutamiento simple y expresivo

¿Por qué usar Express.js?

Comparado con el módulo http nativo de Node.js:

Aspecto Módulo http Express.js
Configuración Más código manual Configuración simple
Rutas Manejo manual con if/else Sistema de rutas integrado
Middleware No disponible Sistema completo de middleware
JSON Parseo manual Parseo automático
Comunidad Limitada Ecosistema enorme

¿Para qué se usa Express.js?

  • Crear APIs RESTful
  • Desarrollar aplicaciones web del lado del servidor
  • Crear servidores para aplicaciones SPA (Single Page Applications)
  • Desarrollar microservicios
  • Crear backends para aplicaciones móviles

📦 Instalación de Express.js

Express.js se instala como un paquete de npm. Ya lo instalaste en la clase anterior, pero aquí está el proceso completo.

Paso 1: Crear un proyecto

mkdir mi-servidor-express
cd mi-servidor-express
npm init -y

Paso 2: Instalar Express

npm install express

Esto instalará Express y lo agregará a tu package.json en dependencies.

Paso 3: Verificar la instalación

Verifica que Express se instaló correctamente:

npm list express

Deberías ver la versión instalada (ej: express@4.18.2)

🌐 Tu Primer Servidor con Express

Vamos a crear un servidor básico paso a paso.

Servidor básico

Crea un archivo index.js:

// Importar Express
const express = require('express');

// Crear una aplicación Express
const app = express();

// Definir el puerto
const PORT = 3000;

// Crear una ruta básica
app.get('/', (req, res) => {
  res.send('¡Hola desde Express.js!');
});

// Iniciar el servidor
app.listen(PORT, () => {
  console.log(`Servidor corriendo en http://localhost:${PORT}`);
});

Ejecutar el servidor

node index.js

Deberías ver: Servidor corriendo en http://localhost:3000

Probar el servidor

Abre tu navegador y ve a http://localhost:3000. Deberías ver el mensaje "¡Hola desde Express.js!"

💡 Tip: Para detener el servidor, presiona Ctrl + C en la terminal.

🛣️ Rutas (Routes)

Las rutas definen cómo tu aplicación responde a peticiones del cliente a un endpoint específico (URI) y un método HTTP específico (GET, POST, etc.).

Métodos HTTP básicos

  • GET: Obtener datos (leer)
  • POST: Crear nuevos datos
  • PUT: Actualizar datos existentes
  • DELETE: Eliminar datos

Rutas básicas

const express = require('express');
const app = express();

// Ruta GET - Obtener datos
app.get('/', (req, res) => {
  res.send('Página principal');
});

app.get('/about', (req, res) => {
  res.send('Acerca de nosotros');
});

// Ruta POST - Crear datos
app.post('/usuarios', (req, res) => {
  res.send('Usuario creado');
});

// Ruta PUT - Actualizar datos
app.put('/usuarios/:id', (req, res) => {
  res.send(`Actualizar usuario ${req.params.id}`);
});

// Ruta DELETE - Eliminar datos
app.delete('/usuarios/:id', (req, res) => {
  res.send(`Eliminar usuario ${req.params.id}`);
});

app.listen(3000, () => {
  console.log('Servidor en http://localhost:3000');
});

Rutas con parámetros

Puedes capturar valores de la URL usando :nombreParametro:

// Obtener un usuario por ID
app.get('/usuarios/:id', (req, res) => {
  const userId = req.params.id;
  res.send(`Usuario ID: ${userId}`);
});

// Múltiples parámetros
app.get('/usuarios/:userId/posts/:postId', (req, res) => {
  const { userId, postId } = req.params;
  res.send(`Usuario ${userId}, Post ${postId}`);
});

// Ejemplos de URLs:
// GET /usuarios/123 → "Usuario ID: 123"
// GET /usuarios/5/posts/10 → "Usuario 5, Post 10"

Query Parameters

Los query parameters son valores que vienen después de ? en la URL:

// URL: /buscar?q=express&tipo=framework
app.get('/buscar', (req, res) => {
  const query = req.query.q;        // "express"
  const tipo = req.query.tipo;      // "framework"
  
  res.send(`Buscando: ${query}, Tipo: ${tipo}`);
});

// También puedes acceder a todo el objeto query
app.get('/productos', (req, res) => {
  console.log(req.query);
  // Si la URL es: /productos?categoria=electronica&precio=100
  // req.query será: { categoria: 'electronica', precio: '100' }
  res.json(req.query);
});

Múltiples rutas para el mismo endpoint

// Diferentes métodos para el mismo endpoint
app.get('/api/usuarios', (req, res) => {
  res.send('Obtener todos los usuarios');
});

app.post('/api/usuarios', (req, res) => {
  res.send('Crear un nuevo usuario');
});

app.put('/api/usuarios', (req, res) => {
  res.send('Actualizar usuarios');
});

app.delete('/api/usuarios', (req, res) => {
  res.send('Eliminar usuarios');
});

📨 Request y Response

Express proporciona objetos req (request) y res (response) que contienen información sobre la petición y permiten enviar respuestas.

Objeto Request (req)

Contiene información sobre la petición HTTP:

app.get('/ejemplo', (req, res) => {
  // Parámetros de la URL
  console.log(req.params);      // { id: '123' } si la ruta es /ejemplo/:id
  
  // Query parameters
  console.log(req.query);       // { nombre: 'valor' } de ?nombre=valor
  
  // Cuerpo de la petición (necesita middleware)
  console.log(req.body);        // Datos enviados en POST/PUT
  
  // Headers
  console.log(req.headers);      // Todos los headers
  console.log(req.get('Content-Type')); // Header específico
  
  // Método HTTP
  console.log(req.method);       // 'GET', 'POST', etc.
  
  // URL completa
  console.log(req.url);          // '/ejemplo?param=value'
  console.log(req.path);         // '/ejemplo'
  
  res.send('Revisa la consola');
});

Objeto Response (res)

Métodos para enviar respuestas:

app.get('/respuestas', (req, res) => {
  // Enviar texto plano
  res.send('Texto simple');
  
  // Enviar JSON
  res.json({ mensaje: 'Hola', estado: 'ok' });
  
  // Enviar con código de estado
  res.status(404).send('No encontrado');
  res.status(201).json({ id: 1, nombre: 'Usuario' });
  
  // Enviar HTML
  res.send('<h1>Título</h1><p>Párrafo</p>');
  
  // Redirigir
  res.redirect('/otra-ruta');
  
  // Enviar archivo
  // res.sendFile(path.join(__dirname, 'public', 'index.html'));
});

Códigos de estado HTTP comunes

Código Significado Uso
200 OK Petición exitosa
201 Created Recurso creado exitosamente
400 Bad Request Error en la petición del cliente
404 Not Found Recurso no encontrado
500 Internal Server Error Error en el servidor

⚙️ Middleware

El middleware son funciones que tienen acceso al objeto de petición (req), al objeto de respuesta (res), y a la siguiente función de middleware en el ciclo de petición/respuesta de la aplicación.

¿Qué es middleware?

El middleware puede:

  • Ejecutar código
  • Modificar los objetos req y res
  • Terminar el ciclo de petición/respuesta
  • Llamar a la siguiente función de middleware

Middleware incorporado: express.json()

Permite que Express parsee el cuerpo de las peticiones en formato JSON:

const express = require('express');
const app = express();

// Middleware para parsear JSON
app.use(express.json());

// Ahora puedes recibir JSON en el body
app.post('/usuarios', (req, res) => {
  console.log(req.body);  // Objeto JavaScript parseado
  const { nombre, email } = req.body;
  res.json({ mensaje: 'Usuario recibido', datos: req.body });
});

// Ejemplo de petición POST con JSON:
// {
//   "nombre": "Juan",
//   "email": "juan@example.com"
// }

Middleware incorporado: express.static()

Sirve archivos estáticos (HTML, CSS, imágenes, etc.):

const express = require('express');
const path = require('path');
const app = express();

// Servir archivos estáticos desde la carpeta 'public'
app.use(express.static('public'));

// Ahora puedes acceder a:
// http://localhost:3000/index.html
// http://localhost:3000/style.css
// http://localhost:3000/imagen.jpg

// Si los archivos están en otra carpeta:
app.use(express.static(path.join(__dirname, 'assets')));

Middleware personalizado

Puedes crear tu propio middleware:

const express = require('express');
const app = express();

// Middleware personalizado - se ejecuta en cada petición
app.use((req, res, next) => {
  console.log(`Petición: ${req.method} ${req.path} - ${new Date().toISOString()}`);
  next(); // Continúa con la siguiente función
});

// Middleware con ruta específica
app.use('/api', (req, res, next) => {
  console.log('Accediendo a la API');
  next();
});

// Middleware que modifica la respuesta
app.use((req, res, next) => {
  // Agregar un header personalizado
  res.setHeader('X-Custom-Header', 'Mi-Valor');
  next();
});

app.get('/', (req, res) => {
  res.send('Página principal');
});

Orden del middleware

Importante: El orden en que defines el middleware importa. Se ejecutan en el orden en que se definen:

app.use(express.json());        // 1. Primero parsea JSON
app.use(express.static('public')); // 2. Luego sirve archivos estáticos
app.use((req, res, next) => {     // 3. Luego tu middleware personalizado
  console.log('Middleware personalizado');
  next();
});

app.get('/', (req, res) => {       // 4. Finalmente las rutas
  res.send('Hola');
});

🎯 Ejemplo Práctico Completo

Vamos a crear una API simple para gestionar una lista de tareas (To-Do List).

Estructura del proyecto

todo-api/
├── package.json
├── index.js
└── data/
    └── todos.json

Código completo

const express = require('express');
const fs = require('fs');
const path = require('path');
const app = express();
const PORT = 3000;

// Middleware
app.use(express.json());

// Ruta para obtener todos los todos
app.get('/api/todos', (req, res) => {
  try {
    const data = fs.readFileSync(path.join(__dirname, 'data', 'todos.json'), 'utf8');
    const todos = JSON.parse(data);
    res.json(todos);
  } catch (error) {
    res.status(500).json({ error: 'Error al leer los todos' });
  }
});

// Ruta para obtener un todo por ID
app.get('/api/todos/:id', (req, res) => {
  try {
    const data = fs.readFileSync(path.join(__dirname, 'data', 'todos.json'), 'utf8');
    const todos = JSON.parse(data);
    const todo = todos.find(t => t.id === parseInt(req.params.id));
    
    if (todo) {
      res.json(todo);
    } else {
      res.status(404).json({ error: 'Todo no encontrado' });
    }
  } catch (error) {
    res.status(500).json({ error: 'Error al leer los todos' });
  }
});

// Ruta para crear un nuevo todo
app.post('/api/todos', (req, res) => {
  try {
    const data = fs.readFileSync(path.join(__dirname, 'data', 'todos.json'), 'utf8');
    const todos = JSON.parse(data);
    
    const newTodo = {
      id: todos.length + 1,
      titulo: req.body.titulo,
      completado: false
    };
    
    todos.push(newTodo);
    fs.writeFileSync(
      path.join(__dirname, 'data', 'todos.json'),
      JSON.stringify(todos, null, 2)
    );
    
    res.status(201).json(newTodo);
  } catch (error) {
    res.status(500).json({ error: 'Error al crear el todo' });
  }
});

// Ruta para actualizar un todo
app.put('/api/todos/:id', (req, res) => {
  try {
    const data = fs.readFileSync(path.join(__dirname, 'data', 'todos.json'), 'utf8');
    const todos = JSON.parse(data);
    const index = todos.findIndex(t => t.id === parseInt(req.params.id));
    
    if (index !== -1) {
      todos[index] = { ...todos[index], ...req.body };
      fs.writeFileSync(
        path.join(__dirname, 'data', 'todos.json'),
        JSON.stringify(todos, null, 2)
      );
      res.json(todos[index]);
    } else {
      res.status(404).json({ error: 'Todo no encontrado' });
    }
  } catch (error) {
    res.status(500).json({ error: 'Error al actualizar el todo' });
  }
});

// Ruta para eliminar un todo
app.delete('/api/todos/:id', (req, res) => {
  try {
    const data = fs.readFileSync(path.join(__dirname, 'data', 'todos.json'), 'utf8');
    const todos = JSON.parse(data);
    const filteredTodos = todos.filter(t => t.id !== parseInt(req.params.id));
    
    if (filteredTodos.length < todos.length) {
      fs.writeFileSync(
        path.join(__dirname, 'data', 'todos.json'),
        JSON.stringify(filteredTodos, null, 2)
      );
      res.json({ mensaje: 'Todo eliminado' });
    } else {
      res.status(404).json({ error: 'Todo no encontrado' });
    }
  } catch (error) {
    res.status(500).json({ error: 'Error al eliminar el todo' });
  }
});

// Iniciar el servidor
app.listen(PORT, () => {
  console.log(`Servidor corriendo en http://localhost:${PORT}`);
});

Archivo de datos inicial: data/todos.json

[
  {
    "id": 1,
    "titulo": "Aprender Express.js",
    "completado": false
  },
  {
    "id": 2,
    "titulo": "Crear una API",
    "completado": false
  }
]

Probar la API

Puedes probar las rutas con:

  • Navegador: http://localhost:3000/api/todos (solo GET)
  • Postman: Para probar POST, PUT, DELETE
  • curl: Desde la terminal

Ejemplos con curl

# GET - Obtener todos los todos
curl http://localhost:3000/api/todos

# GET - Obtener un todo por ID
curl http://localhost:3000/api/todos/1

# POST - Crear un nuevo todo
curl -X POST http://localhost:3000/api/todos \
  -H "Content-Type: application/json" \
  -d '{"titulo": "Nueva tarea"}'

# PUT - Actualizar un todo
curl -X PUT http://localhost:3000/api/todos/1 \
  -H "Content-Type: application/json" \
  -d '{"completado": true}'

# DELETE - Eliminar un todo
curl -X DELETE http://localhost:3000/api/todos/1

📁 Organización de Código

A medida que tu aplicación crece, es importante organizar el código en módulos separados.

Separar rutas en archivos

Crea un archivo routes/todos.js:

// routes/todos.js
const express = require('express');
const router = express.Router();

router.get('/', (req, res) => {
  res.json({ mensaje: 'Obtener todos los todos' });
});

router.get('/:id', (req, res) => {
  res.json({ mensaje: `Obtener todo ${req.params.id}` });
});

router.post('/', (req, res) => {
  res.json({ mensaje: 'Crear todo' });
});

module.exports = router;

En tu index.js:

const express = require('express');
const todosRouter = require('./routes/todos');

const app = express();
app.use(express.json());

// Usar las rutas
app.use('/api/todos', todosRouter);

app.listen(3000, () => {
  console.log('Servidor en http://localhost:3000');
});

❓ Preguntas / Mini desafío

¿Cuál es la diferencia entre res.send() y res.json()?

res.send() puede enviar diferentes tipos de contenido (texto, HTML, JSON) y Express determina el Content-Type automáticamente. res.json() es específico para JSON y establece el Content-Type como application/json. Para APIs, es mejor usar res.json().

¿Qué es middleware y por qué es importante?

El middleware son funciones que se ejecutan entre la recepción de una petición y el envío de una respuesta. Permiten procesar datos, validar información, agregar headers, y más. Es importante porque permite reutilizar lógica común en múltiples rutas.

¿Cuál es la diferencia entre req.params y req.query?

req.params contiene los parámetros de ruta (ej: /usuarios/:id → req.params.id). req.query contiene los query parameters de la URL (ej: ?nombre=valor → req.query.nombre).

¿Por qué necesito express.json() para recibir datos JSON?

Por defecto, Express no parsea el cuerpo de las peticiones. express.json() es un middleware que convierte el cuerpo de la petición (que viene como string) en un objeto JavaScript que puedes usar en req.body.

¿Qué hace next() en un middleware?

next() le dice a Express que continúe con el siguiente middleware o ruta en la cadena. Si no llamas next(), la petición se quedará "colgada" y nunca llegará a las rutas.
