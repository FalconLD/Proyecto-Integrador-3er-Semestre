Clase: Control de flujo, Funciones y DOM

Material de apoyo para estudiantes — desarrollo web.

Objetivo

Aprender a controlar el flujo de ejecución del código con condicionales y bucles, crear funciones reutilizables, y entender qué es el DOM y cómo interactuar con él.

🔀 Condicionales

Los condicionales permiten que tu código tome decisiones y ejecute diferentes bloques de código según ciertas condiciones.

if / else

La estructura más básica para tomar decisiones:

let edad = 18;

if (edad >= 18) {
  console.log("Eres mayor de edad");
} else {
  console.log("Eres menor de edad");
}

else if

Para múltiples condiciones:

let nota = 85;

if (nota >= 90) {
  console.log("Excelente");
} else if (nota >= 70) {
  console.log("Bueno");
} else if (nota >= 60) {
  console.log("Aprobado");
} else {
  console.log("Reprobado");
}

Operador ternario

Una forma abreviada de escribir if/else simple:

let edad = 20;
let mensaje = edad >= 18 ? "Mayor de edad" : "Menor de edad";
console.log(mensaje);

// Equivale a:
// if (edad >= 18) {
//   mensaje = "Mayor de edad";
// } else {
//   mensaje = "Menor de edad";
// }

switch

Útil cuando tienes muchas condiciones basadas en el mismo valor:

let dia = "lunes";

switch (dia) {
  case "lunes":
  case "martes":
  case "miércoles":
  case "jueves":
  case "viernes":
    console.log("Día laboral");
    break;
  case "sábado":
  case "domingo":
    console.log("Fin de semana");
    break;
  default:
    console.log("Día no válido");
}

💡 Tip: No olvides usar break en cada case del switch, o el código continuará ejecutándose en los siguientes casos (fall-through).

🔄 Bucles

Los bucles permiten ejecutar un bloque de código repetidamente. Son fundamentales para automatizar tareas repetitivas.

for - Bucle tradicional

El bucle más común. Tiene tres partes: inicialización, condición y actualización:

// Imprimir números del 1 al 5
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
// Salida: 1, 2, 3, 4, 5

while

Ejecuta el código mientras la condición sea verdadera:

let contador = 0;

while (contador < 5) {
  console.log(contador);
  contador++; // No olvides incrementar, o tendrás un bucle infinito
}
// Salida: 0, 1, 2, 3, 4

do...while

Similar a while, pero garantiza que el código se ejecute al menos una vez:

let numero = 10;

do {
  console.log(numero);
  numero++;
} while (numero < 5);
// Salida: 10 (se ejecuta una vez aunque la condición sea falsa)

for...of (ES6)

Ideal para iterar sobre arrays y strings:

// Con strings
let palabra = "Hola";
for (let letra of palabra) {
  console.log(letra);
}
// Salida: H, o, l, a

// Con arrays (lo veremos más adelante)
let frutas = ["manzana", "banana", "naranja"];
for (let fruta of frutas) {
  console.log(fruta);
}
// Salida: manzana, banana, naranja

Control de bucles: break y continue

  • break - Sale completamente del bucle
  • continue - Salta a la siguiente iteración del bucle
// break: salir cuando encontramos el número 3
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    break; // Sale del bucle
  }
  console.log(i);
}
// Salida: 1, 2

// continue: saltar el número 3
for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    continue; // Salta esta iteración
  }
  console.log(i);
}
// Salida: 1, 2, 4, 5

Bucles anidados

Puedes poner bucles dentro de otros bucles:

// Crear una tabla de multiplicar
for (let i = 1; i <= 3; i++) {
  for (let j = 1; j <= 3; j++) {
    console.log(`${i} × ${j} = ${i * j}`);
  }
}
// Salida: 1×1=1, 1×2=2, 1×3=3, 2×1=2, 2×2=4, etc.

⚠️ Cuidado con los bucles infinitos: Asegúrate de que la condición del bucle eventualmente se vuelva falsa, o tu programa se quedará ejecutándose para siempre.

⚙️ Funciones

Las funciones son bloques de código reutilizables que realizan una tarea específica. Permiten organizar el código y evitar repetición.

¿Por qué usar funciones?

  • Reutilización: Escribe el código una vez, úsalo muchas veces
  • Organización: Divide problemas complejos en partes más pequeñas
  • Mantenimiento: Cambia el código en un solo lugar
  • Legibilidad: El código es más fácil de entender

Declaración de función

La forma tradicional de crear una función:

function saludar(nombre) {
  console.log(`Hola, ${nombre}!`);
}

saludar("Juan");  // Hola, Juan!
saludar("María"); // Hola, María!

Funciones con retorno

Las funciones pueden devolver valores usando return:

function sumar(a, b) {
  return a + b;
}

let resultado = sumar(5, 3);
console.log(resultado); // 8

// También puedes usar directamente
console.log(sumar(10, 20)); // 30

Parámetros y argumentos

  • Parámetros: Variables en la definición de la función
  • Argumentos: Valores que pasas cuando llamas la función
function multiplicar(a, b) {  // a y b son parámetros
  return a * b;
}

multiplicar(4, 5);  // 4 y 5 son argumentos
multiplicar(2, 10);  // 2 y 10 son argumentos

Valores por defecto (ES6)

Puedes asignar valores por defecto a los parámetros:

function saludar(nombre = "Visitante") {
  console.log(`Hola, ${nombre}!`);
}

saludar("Juan");     // Hola, Juan!
saludar();           // Hola, Visitante!

Expresión de función

Guardar una función en una variable:

let restar = function(a, b) {
  return a - b;
};

console.log(restar(10, 3)); // 7

Arrow Functions (ES6)

Sintaxis moderna y más corta para funciones:

// Forma tradicional
let sumar1 = function(a, b) {
  return a + b;
};

// Arrow function equivalente
let sumar2 = (a, b) => {
  return a + b;
};

// Arrow function con retorno implícito (una sola línea)
let sumar3 = (a, b) => a + b;

// Arrow function con un solo parámetro (sin paréntesis)
let duplicar = x => x * 2;

console.log(sumar1(2, 3));  // 5
console.log(sumar2(2, 3));  // 5
console.log(sumar3(2, 3));  // 5
console.log(duplicar(5));   // 10

Ámbito (Scope) de variables

Las variables dentro de una función son locales a esa función:

let variableGlobal = "Soy global";

function miFuncion() {
  let variableLocal = "Soy local";
  console.log(variableGlobal);  // ✅ Puede acceder
  console.log(variableLocal);   // ✅ Puede acceder
}

miFuncion();
console.log(variableGlobal);  // ✅ Puede acceder
// console.log(variableLocal); // ❌ Error: variableLocal no está definida

Ejemplos prácticos

// Función para calcular el área de un círculo
function areaCirculo(radio) {
  return Math.PI * radio * radio;
}

console.log(areaCirculo(5)); // ~78.54

// Función para verificar si un número es par
function esPar(numero) {
  return numero % 2 === 0;
}

console.log(esPar(4));  // true
console.log(esPar(7));  // false

// Función para obtener el mayor de dos números
let mayor = (a, b) => a > b ? a : b;

console.log(mayor(10, 5)); // 10

🌐 Introducción al DOM

El DOM (Document Object Model) es la representación de tu página HTML como un objeto que JavaScript puede manipular.

¿Qué es el DOM?

DOM significa Document Object Model (Modelo de Objetos del Documento).

  • Es una representación en forma de árbol de todos los elementos HTML de tu página
  • Cada elemento HTML se convierte en un nodo en el árbol del DOM
  • JavaScript puede leer, modificar, agregar y eliminar elementos del DOM
  • Los cambios en el DOM se reflejan inmediatamente en la página

¿Para qué sirve el DOM?

El DOM permite hacer que las páginas web sean dinámicas e interactivas:

  • Cambiar contenido: Modificar texto, imágenes, estilos
  • Responder a eventos: Clicks, teclas, movimientos del mouse
  • Agregar/eliminar elementos: Crear nuevos elementos HTML dinámicamente
  • Validar formularios: Verificar datos antes de enviarlos
  • Crear animaciones: Cambiar estilos gradualmente
  • Hacer peticiones: Actualizar contenido sin recargar la página

Estructura del DOM

Imagina este HTML:

<html>
  <head>
    <title>Mi página</title>
  </head>
  <body>
    <h1>Título</h1>
    <p>Párrafo</p>
  </body>
</html>

El DOM lo representa como un árbol:

document (raíz)
  └── html
      ├── head
      │   └── title
      │       └── "Mi página"
      └── body
          ├── h1
          │   └── "Título"
          └── p
              └── "Párrafo"

Seleccionar elementos del DOM

JavaScript proporciona métodos para encontrar elementos en el DOM:

// Por ID (retorna un elemento)
let titulo = document.getElementById("miTitulo");

// Por clase (retorna una colección)
let parrafos = document.getElementsByClassName("parrafo");

// Por etiqueta (retorna una colección)
let divs = document.getElementsByTagName("div");

// Selector moderno (retorna el primer elemento que coincida)
let elemento = document.querySelector("#miId .miClase");

// Selector moderno (retorna todos los elementos que coincidan)
let elementos = document.querySelectorAll(".miClase");

Manipular contenido

Una vez que seleccionas un elemento, puedes cambiar su contenido:

// Cambiar el texto interno
let parrafo = document.querySelector("p");
parrafo.textContent = "Nuevo texto";

// Cambiar el HTML interno (permite etiquetas)
parrafo.innerHTML = "<strong>Texto en negrita</strong>";

// Cambiar atributos
let imagen = document.querySelector("img");
imagen.src = "nueva-imagen.jpg";
imagen.alt = "Nueva descripción";

Cambiar estilos

Puedes modificar los estilos CSS de los elementos:

let titulo = document.querySelector("h1");

// Cambiar un estilo específico
titulo.style.color = "blue";
titulo.style.fontSize = "24px";
titulo.style.backgroundColor = "yellow";

// Agregar o quitar clases CSS
titulo.classList.add("destacado");
titulo.classList.remove("destacado");
titulo.classList.toggle("activo"); // Agrega si no existe, quita si existe

Ejemplo práctico básico

Aquí tienes un ejemplo completo que puedes probar:

<!DOCTYPE html>
<html>
<head>
  <title>Ejemplo DOM</title>
</head>
<body>
  <h1 id="titulo">Hola Mundo</h1>
  <button onclick="cambiarTexto()">Cambiar Texto</button>

  <script>
    function cambiarTexto() {
      let titulo = document.getElementById("titulo");
      titulo.textContent = "¡Texto cambiado!";
      titulo.style.color = "red";
    }
  </script>
</body>
</html>

💡 Nota importante: En esta clase solo vemos una introducción al DOM. En clases futuras profundizaremos en eventos, manipulación avanzada del DOM, y cómo crear aplicaciones interactivas completas.

❓ Preguntas / Mini desafío

¿Cuál es la diferencia entre break y continue en un bucle?

break sale completamente del bucle, mientras que continue salta a la siguiente iteración del bucle sin ejecutar el resto del código en la iteración actual.

¿Cuándo usar if/else y cuándo usar switch?

Usa if/else para condiciones complejas o rangos de valores. Usa switch cuando tengas muchas comparaciones basadas en el mismo valor exacto.

¿Qué diferencia hay entre una función declarada y una arrow function?

Las funciones declaradas se pueden llamar antes de ser definidas (hoisting), mientras que las arrow functions no. Además, las arrow functions tienen un comportamiento diferente con this (lo veremos más adelante).

¿Qué es el DOM y por qué es importante?

El DOM es la representación de tu página HTML como un objeto que JavaScript puede manipular. Es importante porque permite hacer páginas web dinámicas e interactivas, cambiando contenido, estilos y estructura sin recargar la página.

¿Cuál es la diferencia entre textContent e innerHTML?

textContent establece o obtiene solo el texto plano del elemento, mientras que innerHTML permite incluir etiquetas HTML. Usa textContent cuando solo necesites texto (más seguro), e innerHTML cuando necesites HTML.
