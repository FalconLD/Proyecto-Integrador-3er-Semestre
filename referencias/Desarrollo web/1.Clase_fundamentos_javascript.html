Clase: Introducción a JavaScript

Material de apoyo para estudiantes — desarrollo web.

Objetivo

Aprender los fundamentos básicos de JavaScript, incluyendo conceptos básicos, cómo ejecutar código, variables, tipos de datos y operadores.

📚 Conceptos básicos

JavaScript es un lenguaje de programación que permite agregar interactividad a las páginas web. Es uno de los lenguajes más populares del mundo y se ejecuta en el navegador.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación interpretado y dinámico. Esto significa que:

  • No necesita compilación previa (a diferencia de lenguajes como C++ o Java)
  • Se ejecuta directamente en el navegador o en el servidor (Node.js)
  • Es de tipado débil (las variables pueden cambiar de tipo durante la ejecución)
  • Es multiparadigma (permite programación orientada a objetos, funcional, etc.)

¿Dónde se ejecuta JavaScript?

  • En el navegador: Chrome, Firefox, Safari, Edge, etc. (lado del cliente)
  • En el servidor: Con Node.js puedes ejecutar JavaScript fuera del navegador
  • En aplicaciones móviles: Con frameworks como React Native
  • En bases de datos: Como MongoDB que usa JavaScript

¿Para qué sirve JavaScript?

JavaScript permite hacer que las páginas web sean:

  • Interactivas: Responder a clics, movimientos del mouse, teclado
  • Dinámicas: Cambiar contenido sin recargar la página
  • Responsivas: Adaptarse a diferentes dispositivos y tamaños de pantalla
  • Modernas: Crear aplicaciones web complejas (SPA - Single Page Applications)

JavaScript en el ecosistema web

JavaScript es parte fundamental de las tecnologías web junto con:

  • HTML: Define la estructura del contenido (el "qué")
  • CSS: Define el estilo y la presentación (el "cómo se ve")
  • JavaScript: Define el comportamiento y la interactividad (el "qué hace")

Piensa en ellos como: HTML = esqueleto, CSS = apariencia, JavaScript = cerebro y músculos.

Casos de uso comunes

  • Validar formularios antes de enviarlos
  • Crear menús desplegables y animaciones
  • Hacer peticiones a servidores (AJAX/Fetch)
  • Manipular el DOM (cambiar elementos de la página)
  • Crear juegos y aplicaciones interactivas
  • Desarrollar aplicaciones web completas (frontend y backend)

¿Por qué aprender JavaScript?

  • Es el lenguaje más utilizado en desarrollo web
  • Es relativamente fácil de aprender para principiantes
  • Tiene una gran comunidad y muchos recursos disponibles
  • Se usa tanto en frontend como en backend (full-stack)
  • Es esencial para cualquier desarrollador web moderno
  • Ofrece muchas oportunidades laborales

Historia breve

  • 1995: Creado por Brendan Eich para Netscape en solo 10 días
  • 1997: Se estandariza como ECMAScript
  • 2009: Nace Node.js, permitiendo JavaScript en el servidor
  • 2015: ECMAScript 6 (ES6) introduce muchas mejoras modernas
  • Hoy: Uno de los lenguajes más populares y demandados

¿Qué es ECMAScript?

ECMAScript es el estándar oficial que define cómo debe funcionar JavaScript. Es la especificación técnica del lenguaje.

  • ECMA: European Computer Manufacturers Association (ahora Ecma International)
  • JavaScript: Es la implementación práctica de ECMAScript
  • Relación: ECMAScript es la especificación, JavaScript es el lenguaje que la implementa

Es similar a cómo HTML tiene su estándar (W3C) y los navegadores lo implementan. ECMAScript define las reglas, y JavaScript (junto con otros lenguajes como ActionScript) las sigue.

Versiones importantes de ECMAScript

  • ES5 (2009): Versión estable y ampliamente soportada
  • ES6 / ES2015: Introdujo clases, arrow functions, template literals, let/const, y muchas otras características modernas
  • ES2016, ES2017, etc.: Desde 2015, se lanzan nuevas versiones cada año con mejoras incrementales
  • ESNext: Término que se refiere a las próximas versiones o características experimentales

Cuando escuches términos como "ES6", "ES2015", "ES2017", se refieren a diferentes versiones del estándar ECMAScript. JavaScript moderno generalmente se refiere a ES6 y versiones posteriores.

⚙️ Cómo ejecutar JavaScript

Hay varias formas de ejecutar código JavaScript. Las más comunes para empezar son:

1. En el navegador (Consola del desarrollador)

Presiona F12 o Ctrl + Shift + I (Windows/Linux) o Cmd + Option + I (Mac) para abrir las herramientas de desarrollador.

Ve a la pestaña "Console" y escribe tu código directamente.

console.log("¡Hola, mundo!");

2. En un archivo HTML

Puedes incluir JavaScript directamente en tu HTML usando la etiqueta <script>:

<script>
  console.log("Mi primer código JavaScript");
</script>

3. Archivo JavaScript externo

También puedes crear un archivo .js y enlazarlo en tu HTML:

<script src="mi-archivo.js"></script>

📦 Variables

Las variables son contenedores que almacenan valores. En JavaScript puedes declarar variables de tres formas principales:

Declaración de variables

  • let - Para variables que pueden cambiar su valor
  • const - Para constantes (valores que no cambian)
  • var - Forma antigua (no recomendada en código moderno)

Ejemplos

let nombre = "Juan";
let edad = 25;
const PI = 3.14159;

// Puedes cambiar el valor de una variable declarada con let
nombre = "María";
edad = 30;

// Pero no puedes cambiar una constante
// PI = 3.14; // ❌ Esto daría un error

Reglas para nombres de variables

  • Pueden contener letras, números, guiones bajos (_) y signos de dólar ($)
  • Deben comenzar con una letra, _ o $
  • Son sensibles a mayúsculas y minúsculas (edad ≠ Edad)
  • No pueden ser palabras reservadas (let, const, if, for, etc.)
let nombreUsuario = "Juan";  // ✅ Correcto
let nombre_usuario = "Juan"; // ✅ Correcto
let nombreUsuario123 = "Juan"; // ✅ Correcto
let 123nombre = "Juan";      // ❌ Incorrecto (empieza con número)
let let = "Juan";            // ❌ Incorrecto (palabra reservada)

🧩 Tipos de datos

JavaScript tiene varios tipos de datos. Los más importantes para empezar son:

Tipos primitivos

  • String (Cadena de texto): Texto entre comillas
  • Number (Número): Números enteros o decimales
  • Boolean (Booleano): Solo puede ser true o false
  • Null: Representa la ausencia intencional de valor
  • Undefined: Variable declarada pero sin valor asignado

Ejemplos

// String
let nombre = "Juan";
let apellido = 'Pérez';
let mensaje = `Hola, ${nombre}`; // Template literal (ES6)

// Number
let edad = 25;
let precio = 99.99;
let temperatura = -5;

// Boolean
let esEstudiante = true;
let tieneTrabajo = false;

// Null
let valor = null;

// Undefined
let indefinido;
console.log(indefinido); // undefined

Verificar el tipo de dato

Puedes usar typeof para saber qué tipo de dato es una variable:

console.log(typeof "Juan");      // "string"
console.log(typeof 25);          // "number"
console.log(typeof true);        // "boolean"
console.log(typeof null);        // "object" (⚠️ esto es un bug conocido)
console.log(typeof undefined);   // "undefined"

🔢 Operadores + Mini ejercicios

Los operadores permiten realizar operaciones con valores y variables.

Operadores aritméticos

  • + Suma
  • - Resta
  • * Multiplicación
  • / División
  • % Módulo (resto de la división)
  • ** Potencia (ES6)
let a = 10;
let b = 3;

console.log(a + b);  // 13
console.log(a - b);  // 7
console.log(a * b);  // 30
console.log(a / b);  // 3.333...
console.log(a % b);  // 1 (resto de 10/3)
console.log(a ** b); // 1000 (10 al cubo)

Operadores de asignación

let x = 5;
x += 3;  // x = x + 3 → x = 8
x -= 2;  // x = x - 2 → x = 6
x *= 2;  // x = x * 2 → x = 12
x /= 3;  // x = x / 3 → x = 4

Operadores de comparación

  • == Igualdad (compara valores, no tipos)
  • === Igualdad estricta (compara valores Y tipos) ⭐ Recomendado
  • != Desigualdad
  • !== Desigualdad estricta ⭐ Recomendado
  • > Mayor que
  • < Menor que
  • >= Mayor o igual que
  • <= Menor o igual que
console.log(5 == "5");   // true (⚠️ convierte tipos)
console.log(5 === "5");  // false (✅ compara tipos también)
console.log(10 > 5);     // true
console.log(10 <= 10);   // true

Operadores lógicos

  • && AND (y) - ambas condiciones deben ser verdaderas
  • || OR (o) - al menos una condición debe ser verdadera
  • ! NOT (no) - invierte el valor booleano
let edad = 20;
let tieneLicencia = true;

console.log(edad >= 18 && tieneLicencia);  // true
console.log(edad < 18 || !tieneLicencia);  // false
console.log(!tieneLicencia);                // false

❓ Preguntas / Mini desafío

¿Cuál es la diferencia entre let y const?

let permite cambiar el valor de la variable después de declararla, mientras que const crea una constante que no puede ser reasignada.

¿Qué diferencia hay entre == y ===?

== compara solo los valores (haciendo conversión de tipos si es necesario), mientras que === compara tanto el valor como el tipo de dato. Se recomienda usar === para evitar errores.

¿Qué tipos de datos primitivos conocemos?

String, Number, Boolean, Null y Undefined.

¿Cómo puedo ver el tipo de dato de una variable?

Usando el operador typeof, por ejemplo: typeof miVariable
