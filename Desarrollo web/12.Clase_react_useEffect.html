Clase: useEffect en React

Manejo de efectos secundarios y ciclo de vida en componentes funcionales — desarrollo React.

Objetivo

Aprender a usar useEffect para ejecutar código después del render, hacer peticiones a APIs, manejar suscripciones y limpiar recursos. Entender las diferentes formas de usar useEffect y cuándo usar cada una.

⚡ useEffect

useEffect te permite ejecutar código después de que el componente se renderiza. Úsalo para hacer peticiones a APIs, configurar timers, o cualquier cosa que necesites hacer "después" del render.

¿Cuándo usar useEffect?

Úsalo cuando necesites:

  • Hacer peticiones HTTP (fetch a APIs)
  • Configurar timers (setTimeout, setInterval)
  • Guardar datos en localStorage
  • Suscribirte a eventos externos

Sintaxis básica

import { useEffect } from 'react';

const MiComponente = () => {
  useEffect(() => {
    // Código que se ejecuta después del render
    console.log('El componente se renderizó');
  });

  return <div>Mi Componente</div>;
};

1. useEffect sin array (se ejecuta siempre)

const Componente = () => {
  useEffect(() => {
    console.log('Se ejecuta después de cada render');
  });
  // ⚠️ Cuidado: puede causar loops infinitos

  return <div>Componente</div>;
};

2. useEffect con array vacío [] (solo al montar)

const Componente = () => {
  useEffect(() => {
    console.log('Solo se ejecuta UNA VEZ al montar');
  }, []); // Array vacío

  return <div>Componente</div>;
};

Útil para cargar datos iniciales de una API.

3. useEffect con dependencias (se ejecuta cuando cambian)

const Componente = () => {
  const [contador, setContador] = useState(0);

  useEffect(() => {
    console.log('Se ejecuta cuando cambia contador');
  }, [contador]); // Array con dependencias

  return <div>Contador: {contador}</div>;
};

Se ejecuta cuando contador cambia.

Ejemplo 1: Cargar datos de una API

import { useState, useEffect } from 'react';

const ListaSabores = () => {
  const [sabores, setSabores] = useState([]);
  const [cargando, setCargando] = useState(true);

  useEffect(() => {
    const obtenerSabores = async () => {
      try {
        const response = await fetch('http://localhost:3000/api/sabores');
        const data = await response.json();
        setSabores(data);
      } catch (error) {
        console.error('Error:', error);
      } finally {
        setCargando(false);
      }
    };

    obtenerSabores();
  }, []); // Solo al montar

  if (cargando) return <div>Cargando...</div>;

  return (
    <ul>
      {sabores.map((sabor) => (
        <li key={sabor.id}>{sabor.nombre} - ${sabor.precio}</li>
      ))}
    </ul>
  );
};

Ejemplo 2: Actualizar cuando cambia una prop

const DetalleSabor = ({ saborId }) => {
  const [sabor, setSabor] = useState(null);

  useEffect(() => {
    const obtenerSabor = async () => {
      const response = await fetch(`http://localhost:3000/api/sabores/${saborId}`);
      const data = await response.json();
      setSabor(data);
    };

    if (saborId) {
      obtenerSabor();
    }
  }, [saborId]); // Se ejecuta cuando cambia saborId

  if (!sabor) return <div>Cargando...</div>;

  return (
    <div>
      <h2>{sabor.nombre}</h2>
      <p>Precio: ${sabor.precio}</p>
    </div>
  );
};

Ejemplo 3: Timer con cleanup

const ContadorTiempo = () => {
  const [segundos, setSegundos] = useState(0);

  useEffect(() => {
    const interval = setInterval(() => {
      setSegundos((prev) => prev + 1);
    }, 1000);

    // Cleanup: limpia el timer cuando el componente se desmonta
    return () => {
      clearInterval(interval);
    };
  }, []); // Solo al montar

  return <div>Tiempo: {segundos} segundos</div>;
};

⚠️ Importante: Siempre limpia timers y suscripciones para evitar memory leaks.

Ejemplo 4: Guardar en localStorage

const GuardarPreferencias = () => {
  const [tema, setTema] = useState('claro');

  useEffect(() => {
    // Guardar cuando cambia el tema
    localStorage.setItem('tema', tema);
  }, [tema]);

  return (
    <button onClick={() => setTema(tema === 'claro' ? 'oscuro' : 'claro')}>
      Tema: {tema}
    </button>
  );
};

🎯 Ejemplo Completo: Lista de Sabores

Combinando useState y useEffect para cargar y mostrar datos de una API.

const ListaSabores = () => {

        setSabores(data);
      } catch (error) {
        console.error('Error:', error);
      } finally {
        setCargando(false);
      }
    };

    cargarSabores();
  }, []); // Solo al montar

  if (cargando) return <div>Cargando...</div>;

  return (
    <div>
      <h2>Sabores Disponibles</h2>
      <ul>
        {sabores.map((sabor) => (

            {sabor.nombre} - ${sabor.precio}

  );
};

⚠️ Errores Comunes

1. Olvidar dependencias

// ❌ MAL - Puede tener valores obsoletos
const [contador, setContador] = useState(0);
useEffect(() => {
  console.log(contador);
}, []); // Falta contador

// ✅ BIEN
useEffect(() => {
  console.log(contador);
}, [contador]); // Incluye la dependencia

2. Loop infinito

// ❌ MAL - Loop infinito
const [contador, setContador] = useState(0);
useEffect(() => {
  setContador(contador + 1); // Causa re-render infinito
}); // Sin array de dependencias

// ✅ BIEN
useEffect(() => {
  // Solo se ejecuta una vez
}, []);

3. No limpiar timers

// ❌ MAL - Memory leak
useEffect(() => {
  const interval = setInterval(() => {
    console.log('Tick');
  }, 1000);
  // Falta cleanup
}, []);

// ✅ BIEN
useEffect(() => {
  const interval = setInterval(() => {
    console.log('Tick');
  }, 1000);
  
  return () => clearInterval(interval); // Cleanup
}, []);

❓ Preguntas / Mini desafío

¿Cuándo se ejecuta useEffect?

Depende del array de dependencias:

  • Sin array: después de cada render (⚠️ puede causar loops)
  • Array vacío []: solo al montar el componente
  • Con dependencias [valor]: cuando valor cambia

¿Qué es una cleanup function?

Es una función que retornas de useEffect. Se ejecuta cuando el componente se desmonta o antes de que el efecto se ejecute de nuevo. Úsala para limpiar timers, suscripciones o listeners.

¿Por qué necesito el array de dependencias?

Le dice a React cuándo ejecutar el efecto. Sin dependencias correctas, puedes tener valores obsoletos o loops infinitos.
