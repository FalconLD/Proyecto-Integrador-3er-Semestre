Clase: Introducción a React.js

Creando interfaces modernas e interactivas — desarrollo web.

Objetivo

Aprender los fundamentos de React.js, el framework más popular para crear interfaces de usuario modernas e interactivas. Entender conceptos clave como componentes, JSX, props, state, y hooks. Crear tu primera aplicación React que se conecte con tu API de Express.

⚛️ ¿Qué es React.js?

React es una biblioteca de JavaScript desarrollada por Facebook (Meta) para crear interfaces de usuario interactivas y dinámicas. Es el framework más popular para desarrollo frontend moderno.

Características principales

  • Componentes: Construyes interfaces dividiéndolas en piezas reutilizables
  • Declarativo: Describes cómo debe verse la UI, React se encarga de actualizarla
  • Virtual DOM: React actualiza solo lo que cambia, haciéndolo muy rápido
  • Unidireccional: Los datos fluyen de arriba hacia abajo (más predecible)
  • Ecosistema enorme: Miles de librerías y herramientas disponibles
  • Comunidad masiva: Muchos recursos, tutoriales y soporte

¿Por qué usar React?

Comparado con JavaScript vanilla (HTML + JS puro):

Aspecto JavaScript Vanilla React.js
Organización Código disperso, difícil de mantener Componentes organizados y reutilizables
Actualizaciones Debes actualizar el DOM manualmente React actualiza automáticamente cuando cambian los datos
Estado Variables globales, difícil de rastrear State local en cada componente
Reutilización Copiar y pegar código Componentes reutilizables con props
Escalabilidad Se vuelve complejo rápidamente Fácil de escalar con componentes

¿Para qué se usa React?

  • Aplicaciones web modernas (SPA - Single Page Applications)
  • Dashboards y paneles de administración
  • Redes sociales (Facebook, Instagram, Twitter usan React)
  • E-commerce y tiendas online
  • Aplicaciones móviles (con React Native)
  • Interfaces de usuario complejas e interactivas

Ecosistema React

React es parte de un ecosistema más grande:

  • React: La biblioteca core
  • React Router: Para navegación entre páginas
  • Redux: Para manejo de estado global
  • Next.js: Framework completo con React (SSR, routing, etc.)
  • React Native: Para crear apps móviles

⚡ ¿Qué es Vite?

Antes de instalar React, es importante entender qué es Vite y por qué lo usamos para crear proyectos React.

¿Qué es Vite?

Vite (pronunciado "veet", del francés "rápido") es una herramienta de construcción (build tool) moderna para desarrollo frontend. Fue creada por Evan You, el mismo creador de Vue.js, pero funciona perfectamente con React, Vue, Angular y otros frameworks.

¿Para qué sirve Vite?

Vite se encarga de varias tareas importantes en el desarrollo:

  • Servidor de desarrollo: Crea un servidor local para probar tu aplicación mientras desarrollas
  • Compilación rápida: Compila tu código JavaScript/JSX de forma muy rápida
  • Hot Module Replacement (HMR): Actualiza automáticamente la página cuando guardas cambios (sin recargar manualmente)
  • Optimización: Optimiza tu código para producción (minificación, tree-shaking, etc.)
  • Manejo de dependencias: Gestiona las librerías y paquetes que usa tu proyecto

¿Por qué usar Vite en lugar de Create React App?

Create React App (CRA) fue la herramienta tradicional para crear proyectos React, pero Vite ofrece ventajas significativas:

Aspecto Create React App Vite
Velocidad de inicio Lento (puede tardar 30-60 segundos) Muy rápido (1-3 segundos) ⚡
Hot Reload Lento (recarga toda la app) Instantáneo (solo actualiza lo que cambió)
Tamaño del proyecto Más pesado Más ligero
Configuración Oculta la configuración (más difícil de personalizar) Configuración visible y fácil de modificar
Actualizaciones Menos mantenido activamente Muy activo y actualizado
Uso de ES Modules No (usa CommonJS) Sí (nativo, más moderno)

¿Cómo funciona Vite?

Vite usa un enfoque diferente a las herramientas tradicionales:

  • En desarrollo: Sirve tu código directamente usando ES Modules nativos del navegador (sin compilar todo de antemano)
  • En producción: Compila y optimiza tu código usando Rollup (otra herramienta de construcción)
  • Resultado: Desarrollo súper rápido y builds optimizados para producción

Conceptos importantes (sin profundizar demasiado)

  • Build Tool: Herramienta que "construye" tu aplicación (compila, optimiza, empaqueta)
  • Dev Server: Servidor de desarrollo que corre localmente mientras programas
  • Hot Module Replacement (HMR): Actualización instantánea sin recargar toda la página
  • Bundler: Herramienta que "empaqueta" todos tus archivos en archivos optimizados

💡 Nota importante: No necesitas entender todos los detalles técnicos de Vite para usarlo. Solo necesitas saber que es una herramienta que hace tu vida más fácil al desarrollar con React. La mayoría del tiempo solo usarás npm run dev para iniciar el servidor y npm run build para crear la versión de producción.

Alternativa: Create React App

Si prefieres usar Create React App (la herramienta tradicional), también es válido. Funciona igual de bien, solo que es más lento. En esta clase usaremos Vite porque es más moderno y rápido, pero al final ambos te permiten crear aplicaciones React.

📦 Instalación y Configuración

Ahora que entiendes qué es Vite, vamos a crear tu primer proyecto React usando esta herramienta moderna.

Requisitos previos

  • Node.js instalado (versión 18 o superior)
  • npm o yarn
  • Un editor de código (VS Code recomendado)

Paso 1: Crear un nuevo proyecto React con Vite

Vamos a crear tu primer proyecto React usando Vite. Abre tu terminal y ejecuta:

# Crear proyecto con Vite
npm create vite@latest mi-app-react -- --template react

# Navegar al directorio del proyecto
cd mi-app-react

# Instalar todas las dependencias necesarias
npm install

# Iniciar el servidor de desarrollo
npm run dev

¿Qué hace cada comando?

  • npm create vite@latest - Crea un nuevo proyecto usando la última versión de Vite
  • -- --template react - Especifica que queremos usar la plantilla de React
  • npm install - Descarga e instala todas las dependencias del proyecto (React, Vite, etc.)
  • npm run dev - Inicia el servidor de desarrollo de Vite

Alternativa: Usar Create React App

Si prefieres usar Create React App (la herramienta tradicional), puedes hacerlo así:

# Crear proyecto con Create React App
npx create-react-app mi-app-react

# Navegar al directorio
cd mi-app-react

# Iniciar el servidor de desarrollo
npm start

Nota: Create React App es más lento al iniciar, pero funciona igual de bien. En esta clase usaremos Vite por su velocidad.

Paso 2: Estructura del proyecto

Después de crear el proyecto, verás esta estructura:

Paso 3: Verificar que funciona

Al ejecutar npm run dev, deberías ver:

VITE v5.x.x  ready in xxx ms

➜  Local:   http://localhost:5173/
➜  Network: use --host to expose

Abre http://localhost:5173 en tu navegador. Deberías ver la página de bienvenida de React.

💡 Tip - Hot Module Replacement (HMR): Una de las mejores características de Vite es el HMR. Cuando guardas cambios en tu código, Vite actualiza automáticamente solo la parte que cambió en el navegador, sin recargar toda la página. Esto hace el desarrollo mucho más rápido y fluido. ¡Pruébalo guardando un cambio en App.jsx y verás cómo se actualiza instantáneamente!

🧩 Conceptos Básicos de React

Antes de escribir código, entendamos los conceptos fundamentales de React.

1. Componentes

Un componente es una pieza reutilizable de la interfaz. Piensa en ellos como bloques de construcción:

  • Un botón puede ser un componente
  • Un formulario puede ser un componente
  • Una tarjeta de producto puede ser un componente
  • Una página completa puede ser un componente

Los componentes pueden contener otros componentes, creando una estructura en árbol.

2. JSX (JavaScript XML)

JSX es una sintaxis que parece HTML pero es JavaScript. Te permite escribir código que se ve como HTML dentro de JavaScript:

// Esto es JSX
const elemento = <h1>Hola, React!</h1>;

// Se convierte en JavaScript
const elemento = React.createElement('h1', null, 'Hola, React!');

Reglas importantes de JSX:

  • Debes retornar un solo elemento padre (o usar Fragment)
  • Los atributos usan camelCase: className en lugar de class
  • Puedes usar expresiones JavaScript con {}
  • Los comentarios son {/* comentario */}

3. Props (Propiedades)

Props son datos que pasas de un componente padre a un componente hijo. Son inmutables (no puedes cambiarlas dentro del componente hijo).

4. State (Estado)

State es información que puede cambiar dentro de un componente. Cuando el state cambia, React re-renderiza el componente automáticamente.

5. Hooks

Hooks son funciones especiales que te permiten "engancharte" a características de React. Los más comunes:

  • useState - Para manejar estado
  • useEffect - Para efectos secundarios (llamadas a APIs, timers, etc.)
  • useContext - Para compartir datos entre componentes

🎨 Tu Primer Componente

Vamos a crear tu primer componente React paso a paso.

Componente simple

Reemplaza el contenido de src/App.jsx:

const App = () => {
  return (
    <div className="App">
      <h1>¡Hola desde React!</h1>
      <p>Mi primera aplicación React</p>
    </div>
  );
};

export default App;

Componente con JavaScript

Puedes usar JavaScript dentro de JSX con llaves {}:

const App = () => {
  const nombre = "Estudiante";
  const edad = 20;
  
  return (
    <div className="App">
      <h1>¡Hola, {nombre}!</h1>
      <p>Tienes {edad} años</p>
      <p>El año que viene tendrás {edad + 1} años</p>
    </div>
  );
};

export default App;

Componente con funciones

const App = () => {
  const saludar = (nombre) => {
    return `Hola, ${nombre}!`;
  };
  
  const mensaje = saludar("React");
  
  return (
    <div className="App">
      <h1>{mensaje}</h1>
    </div>
  );

💡 Arrow Functions en React: En este material usamos arrow functions const Componente = () => {} para todos los componentes porque son más concisas y modernas. También funcionan perfectamente las funciones tradicionales function Componente() {}, pero las arrow functions son muy populares en la comunidad React moderna. Para handlers dentro de componentes (como onClick, onChange), las arrow functions son muy comunes y recomendadas.

📤 Props (Propiedades)

Las props permiten pasar datos de un componente padre a un componente hijo.

Componente con props

Crea un componente que recibe props:

// Componente Saludo
const Saludo = (props) => {
  return (
    <div>
      <h2>Hola, {props.nombre}!</h2>
      <p>Tienes {props.edad} años</p>
    </div>
  );
};

// Usar el componente
const App = () => {
  return (
    <div className="App">
      <Saludo nombre="Juan" edad={25} />
      <Saludo nombre="María" edad={30} />
    </div>
  );
};

Destructuring de props

Es más común y limpio usar destructuring:

const Saludo = ({ nombre, edad }) => {
  return (
    <div>
      <h2>Hola, {nombre}!</h2>
      <p>Tienes {edad} años</p>
    </div>
  );
};

const App = () => {
  return (
    <div className="App">
      <Saludo nombre="Juan" edad={25} />
      <Saludo nombre="María" edad={30} />
    </div>
  );
};

Props con valores por defecto

const Saludo = ({ nombre = "Visitante", edad = 0 }) => {

// Si no pasas props, usa los valores por defecto
<Saludo /> // "Hola, Visitante! Tienes 0 años"

🔄 State con useState

El state permite que los componentes tengan datos que pueden cambiar. Cuando el state cambia, React re-renderiza el componente automáticamente.

Importar useState

import { useState } from 'react';

Usar useState

La sintaxis es: const [valor, setValor] = useState(valorInicial)

import { useState } from 'react';

const Contador = () => {
  const [contador, setContador] = useState(0);
  
  return (
    <div>
      <p>Contador: {contador}</p>
      <button onClick={() => setContador(contador + 1)}>
        Incrementar
      </button>
      <button onClick={() => setContador(contador - 1)}>
        Decrementar
      </button>
      <button onClick={() => setContador(0)}>
        Resetear
      </button>
    </div>
  );
};

State con arrays

import { useState } from 'react';

const ListaTareas = () => {
  const [tareas, setTareas] = useState([]);
  const [nuevaTarea, setNuevaTarea] = useState('');
  
  const agregarTarea = () => {
    if (nuevaTarea.trim() !== '') {
      setTareas([...tareas, nuevaTarea]);
      setNuevaTarea('');
    }
  };
  
  const eliminarTarea = (index) => {
    setTareas(tareas.filter((_, i) => i !== index));
  };
  
  return (
    <div>
      <input 
        value={nuevaTarea}
        onChange={(e) => setNuevaTarea(e.target.value)}
        placeholder="Nueva tarea"
      />
      <button onClick={agregarTarea}>Agregar</button>
      
      <ul>
        {tareas.map((tarea, index) => (
          <li key={index}>
            {tarea}
            <button onClick={() => eliminarTarea(index)}>Eliminar</button>
          </li>
        ))}
      </ul>
    </div>
  );
};

⚠️ Regla importante: Nunca modifiques el state directamente. Siempre usa la función setter (setContador, setTareas, etc.).

// ❌ MAL
contador = contador + 1;
tareas.push(nuevaTarea);

// ✅ BIEN
setContador(contador + 1);
setTareas([...tareas, nuevaTarea]);

🎯 Eventos en React

Los eventos en React son similares a los eventos en HTML, pero con algunas diferencias importantes.

Sintaxis de eventos

Los eventos en React usan camelCase y se pasan como funciones:

const Boton = () => {
  const handleClick = () => {
    alert('¡Botón clickeado!');
  };
  
  return (
    <button onClick={handleClick}>
      Haz clic
    </button>

Eventos comunes

const EjemploEventos = () => {

⚡ useEffect Hook

useEffect te permite ejecutar código después de que el componente se renderiza. Es útil para llamadas a APIs, suscripciones, timers, etc.

Importar useEffect

import { useState, useEffect } from 'react';

useEffect básico

import { useState, useEffect } from 'react';

const Contador = () => {
  const [contador, setContador] = useState(0);
  
  // Se ejecuta después de cada render
  useEffect(() => {
    console.log('El componente se renderizó');
  });
  
  return (
    <div>
      <p>Contador: {contador}</p>
      <button onClick={() => setContador(contador + 1)}>
        Incrementar
      </button>
    </div>
  );
};

useEffect con dependencias (solo una vez)

import { useState, useEffect } from 'react';

const App = () => {
  const [datos, setDatos] = useState(null);
  
  // Se ejecuta solo una vez al montar el componente
  useEffect(() => {
    console.log('Componente montado');
    // Aquí harías una llamada a una API
  }, []); // Array vacío = solo al montar
  
  return <div>Mi componente</div>;
};

useEffect con dependencias específicas

import { useState, useEffect } from 'react';

const Usuario = ({ userId }) => {
  const [usuario, setUsuario] = useState(null);
  
  // Se ejecuta cuando userId cambia
  useEffect(() => {
    console.log('Cargando usuario:', userId);
    // Aquí harías: fetch(`/api/usuarios/${userId}`)
  }, [userId]); // Se ejecuta cuando userId cambia
  
  return <div>Usuario: {userId}</div>;
};

Limpieza en useEffect

import { useState, useEffect } from 'react';

const Temporizador = () => {
  const [segundos, setSegundos] = useState(0);
  
  useEffect(() => {
    const intervalo = setInterval(() => {
      setSegundos(segundos => segundos + 1);
    }, 1000);
    
    // Función de limpieza (se ejecuta al desmontar)
    return () => {
      clearInterval(intervalo);
    };
  }, []); // Solo al montar
  
  return <div>Segundos: {segundos}</div>;
};

🌐 Llamadas a APIs con fetch()

Conectemos React con tu API de Express que creaste en el taller anterior.

Ejemplo básico: Obtener datos

import { useState, useEffect } from 'react';

const ListaSabores = () => {
  const [sabores, setSabores] = useState([]);
  const [cargando, setCargando] = useState(true);
  const [error, setError] = useState(null);
  
  useEffect(() => {
    // Función para obtener sabores
    const obtenerSabores = async () => {
      try {
        setCargando(true);
        const response = await fetch('http://localhost:3000/api/sabores');
        
        if (!response.ok) {
          throw new Error('Error al obtener sabores');
        }
        
        const datos = await response.json();
        setSabores(datos);
        setError(null);
      } catch (err) {
        setError(err.message);
        console.error('Error:', err);
      } finally {
        setCargando(false);
      }
    };
    
    obtenerSabores();
  }, []); // Solo al montar
  
  if (cargando) return <div>Cargando sabores...</div>;
  if (error) return <div>Error: {error}</div>;
  
  return (
    <div>
      <h2>Sabores de Helado</h2>
      <ul>
        {sabores.map(sabor => (
          <li key={sabor.id}>
            {sabor.nombre} - ${sabor.precio}
            {sabor.disponible ? ' ✅' : ' ❌'}
          </li>
        ))}
      </ul>
    </div>
  );
};

Crear datos (POST)

import { useState } from 'react';

const AgregarSabor = () => {
  const [nombre, setNombre] = useState('');
  const [precio, setPrecio] = useState('');
  const [enviando, setEnviando] = useState(false);
  
  const handleSubmit = async (e) => {
    e.preventDefault();
    setEnviando(true);
    
    try {
      const response = await fetch('http://localhost:3000/api/sabores', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          nombre: nombre,
          precio: parseFloat(precio)
        })
      });
      
      if (!response.ok) {
        throw new Error('Error al crear sabor');
      }
      
      const nuevoSabor = await response.json();
      console.log('Sabor creado:', nuevoSabor);
      
      // Limpiar formulario
      setNombre('');
      setPrecio('');
      
      // Aquí podrías actualizar la lista de sabores
    } catch (error) {
      console.error('Error:', error);
      alert('Error al crear el sabor');
    } finally {
      setEnviando(false);
    }
  };
  
  return (
    <form onSubmit={handleSubmit}>
      <input 
        value={nombre}
        onChange={(e) => setNombre(e.target.value)}
        placeholder="Nombre del sabor"
        required
      />
      <input 
        type="number"
        step="0.01"
        value={precio}
        onChange={(e) => setPrecio(e.target.value)}
        placeholder="Precio"
        required
      />
      <button type="submit" disabled={enviando}>
        {enviando ? 'Enviando...' : 'Agregar Sabor'}
      </button>
    </form>
  );
};

Componente principal: App.jsx

import { useState, useEffect } from 'react';
import ListaSabores from './components/ListaSabores';
import FormularioSabor from './components/FormularioSabor';
import './App.css';

const API_URL = 'http://localhost:3000/api/sabores';

const App = () => {
  const [sabores, setSabores] = useState([]);
  const [cargando, setCargando] = useState(true);
  
  // Cargar sabores al iniciar
  useEffect(() => {
    cargarSabores();
  }, []);
  
  const cargarSabores = async () => {
    try {
      const response = await fetch(API_URL);
      const datos = await response.json();
      setSabores(datos);
    } catch (error) {
      console.error('Error al cargar sabores:', error);
    } finally {
      setCargando(false);
    }
  };
  
  const agregarSabor = async (nombre, precio) => {
    try {
      const response = await fetch(API_URL, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ nombre, precio: parseFloat(precio) })
      });
      
      if (response.ok) {
        await cargarSabores(); // Recargar lista
      }
    } catch (error) {
      console.error('Error al agregar sabor:', error);
    }
  };
  
  const eliminarSabor = async (id) => {
    try {
      const response = await fetch(`${API_URL}/${id}`, {
        method: 'DELETE'
      });
      
      if (response.ok) {
        await cargarSabores(); // Recargar lista
      }
    } catch (error) {
      console.error('Error al eliminar sabor:', error);
    }
  };
  
  const toggleDisponible = async (id, disponible) => {
    try {
      const response = await fetch(`${API_URL}/${id}`, {
        method: 'PUT',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ disponible: !disponible })
      });
      
      if (response.ok) {
        await cargarSabores(); // Recargar lista
      }
    } catch (error) {
      console.error('Error al actualizar sabor:', error);
    }
  };
  
  if (cargando) {
    return <div className="App"><p>Cargando...</p></div>;
  }
  
  return (
    <div className="App">
      <h1>🍦 Gestión de Heladería</h1>
      <FormularioSabor onAgregar={agregarSabor} />
      <ListaSabores 
        sabores={sabores}
        onEliminar={eliminarSabor}
        onToggleDisponible={toggleDisponible}
      />
    </div>
  );
};

export default App;

Componente: FormularioSabor.jsx

import { useState } from 'react';

const FormularioSabor = ({ onAgregar }) => {
  const [nombre, setNombre] = useState('');
  const [precio, setPrecio] = useState('');
  
  const handleSubmit = (e) => {
    e.preventDefault();
    if (nombre.trim() && precio > 0) {
      onAgregar(nombre, precio);
      setNombre('');
      setPrecio('');
    }
  };
  
  return (
    <form onSubmit={handleSubmit} className="formulario">
      <input
        type="text"
        value={nombre}
        onChange={(e) => setNombre(e.target.value)}
        placeholder="Nombre del sabor"
        required
      />
      <input
        type="number"
        step="0.01"
        min="0.01"
        value={precio}
        onChange={(e) => setPrecio(e.target.value)}
        placeholder="Precio"
        required
      />
      <button type="submit">Agregar Sabor</button>
    </form>
  );
};

export default FormularioSabor;

Componente: ListaSabores.jsx

import SaborItem from './SaborItem';

const ListaSabores = ({ sabores, onEliminar, onToggleDisponible }) => {
  if (sabores.length === 0) {
    return <p>No hay sabores. ¡Agrega uno nuevo!</p>;
  }
  
  return (
    <div className="lista-sabores">
      <h2>Inventario de Sabores</h2>
      <ul>
        {sabores.map(sabor => (
          <SaborItem
            key={sabor.id}
            sabor={sabor}
            onEliminar={onEliminar}
            onToggleDisponible={onToggleDisponible}
          />
        ))}
      </ul>
    </div>
  );
};

export default ListaSabores;

Componente: SaborItem.jsx

const SaborItem = ({ sabor, onEliminar, onToggleDisponible }) => {
  return (
    <li className={`sabor-item ${!sabor.disponible ? 'agotado' : ''}`}>
      <input
        type="checkbox"
        checked={sabor.disponible}
        onChange={() => onToggleDisponible(sabor.id, sabor.disponible)}
      />
      <div className="sabor-info">
        <h3>{sabor.nombre}</h3>
        <p>${sabor.precio.toFixed(2)}</p>
      </div>
      <button 
        onClick={() => {
          if (window.confirm(`¿Eliminar ${sabor.nombre}?`)) {
            onEliminar(sabor.id);
          }
        }}
        className="btn-eliminar"
      >
        Eliminar
      </button>
    </li>
  );
};

export default SaborItem;

✅ Buenas Prácticas en React

Sigue estas recomendaciones para escribir código React limpio y mantenible.

1. Nombres de componentes

  • Usa PascalCase para nombres de componentes
  • Nombres descriptivos y claros
// ✅ Bien
const ListaSabores = () => { };
const FormularioUsuario = () => { };

// ❌ Mal
const lista = () => { };
const form = () => { };

2. Keys en listas

Siempre usa key única cuando renderizas listas:

// ✅ Bien
{sabores.map(sabor => (
  <SaborItem key={sabor.id} sabor={sabor} />
))}

// ❌ Mal (usar index solo si no hay otra opción)
{sabores.map((sabor, index) => (
  <SaborItem key={index} sabor={sabor} />
))}

3. Separar componentes

Divide componentes grandes en componentes más pequeños:

// ✅ Bien: Componentes pequeños y reutilizables
const App = () => {
  return (
    <div>
      <Header />
      <Formulario />
      <Lista />
    </div>
  );
};

// ❌ Mal: Todo en un componente gigante
const App = () => {
  // 500 líneas de código...
};

4. Props destructuring

// ✅ Bien
const Saludo = ({ nombre, edad }) => {
  return <h1>Hola, {nombre}</h1>;
};

// ❌ Menos claro
const Saludo = (props) => {
  return <h1>Hola, {props.nombre}</h1>;
};

❓ Preguntas / Mini desafío

¿Cuál es la diferencia entre props y state?

Props son datos que se pasan de un componente padre a un hijo. Son inmutables (no puedes cambiarlas dentro del componente hijo). State es información que puede cambiar dentro de un componente. Cuando el state cambia, React re-renderiza el componente automáticamente.

¿Cuándo usar useEffect sin dependencias, con array vacío, o con dependencias?

Sin dependencias: Se ejecuta después de cada render (raro, puede causar loops infinitos). Array vacío []: Se ejecuta solo una vez al montar el componente (útil para cargar datos iniciales). Con dependencias [valor]: Se ejecuta cuando el valor cambia (útil para actualizar datos cuando cambia un prop).

¿Por qué debo usar keys en listas?

Las key ayudan a React a identificar qué elementos han cambiado, se agregaron o eliminaron. Esto hace que React pueda actualizar solo los elementos necesarios, mejorando el rendimiento. Sin keys, React puede tener problemas para rastrear los elementos correctamente.

¿Cuál es la diferencia entre JavaScript vanilla y React para actualizar la UI?

En JavaScript vanilla, debes seleccionar elementos del DOM y actualizarlos manualmente cada vez que cambian los datos. En React, describes cómo debe verse la UI basada en el state, y React actualiza automáticamente el DOM cuando el state cambia. Esto hace el código más declarativo y fácil de mantener.

¿Qué es JSX y por qué React lo usa?

JSX es una sintaxis que parece HTML pero es JavaScript. Permite escribir código que se ve como HTML dentro de JavaScript, haciendo que los componentes sean más fáciles de leer y escribir. JSX se compila a llamadas a React.createElement(). Es opcional (puedes usar React sin JSX), pero hace el código mucho más legible.

¿Debo usar arrow functions o funciones tradicionales para componentes en React?

Ambas opciones funcionan perfectamente. Las funciones tradicionales function Componente() {} son más explícitas y aparecen con nombre en los stack traces de errores. Las arrow functions const Componente = () => {} son más concisas y modernas. No hay diferencia funcional entre ambas para componentes funcionales en React. En este material usamos arrow functions porque son muy populares en la comunidad React moderna y hacen el código más conciso. Para handlers de eventos dentro de componentes (como handleClick, handleSubmit), las arrow functions son muy comunes y recomendadas.
