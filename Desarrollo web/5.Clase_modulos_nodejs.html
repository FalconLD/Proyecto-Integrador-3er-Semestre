Clase: Módulos en Node.js

Material de apoyo para estudiantes — desarrollo web.

Objetivo

Aprender a organizar código JavaScript en módulos reutilizables usando CommonJS y ES6 Modules. Entender cómo importar y exportar código, trabajar con módulos nativos de Node.js, y crear proyectos modulares y bien estructurados.

📦 ¿Qué son los Módulos?

Los módulos son una forma de organizar y reutilizar código. Permiten dividir tu aplicación en archivos más pequeños y manejables, cada uno con una responsabilidad específica.

¿Por qué usar módulos?

  • Organización: Divide código complejo en partes más pequeñas y manejables
  • Reutilización: Escribe código una vez y úsalo en múltiples lugares
  • Mantenibilidad: Es más fácil encontrar y corregir errores
  • Colaboración: Diferentes desarrolladores pueden trabajar en módulos diferentes
  • Encapsulación: Oculta detalles de implementación, expone solo lo necesario
  • Evita conflictos: Las variables en un módulo no interfieren con otros módulos

Sistemas de módulos en Node.js

Node.js soporta dos sistemas de módulos:

  • CommonJS: El sistema tradicional de Node.js (usa require y module.exports)
  • ES6 Modules: El estándar moderno de JavaScript (usa import y export)

En esta clase aprenderemos ambos sistemas, pero empezaremos con CommonJS ya que es el más común en Node.js y el que usa la mayoría de paquetes de npm.

🔧 CommonJS - El Sistema Tradicional

CommonJS es el sistema de módulos original de Node.js. Es el que encontrarás en la mayoría de proyectos y paquetes de npm.

Exportar con module.exports

Para hacer que código esté disponible en otros archivos, usas module.exports:

// archivo: calculadora.js
function sumar(a, b) {
  return a + b;
}

function restar(a, b) {
  return a - b;
}

// Exportar una función
module.exports = sumar;

// O exportar múltiples cosas como un objeto
module.exports = {
  sumar: sumar,
  restar: restar
};

// Forma abreviada (ES6)
module.exports = {
  sumar,
  restar
};

Importar con require()

Para usar código de otro módulo, usas require():

// archivo: app.js
// Importar el módulo
const calculadora = require('./calculadora');

// Usar las funciones exportadas
console.log(calculadora.sumar(5, 3));  // 8
console.log(calculadora.restar(10, 4)); // 6

// O si solo exportaste una función
const sumar = require('./calculadora');
console.log(sumar(5, 3)); // 8

Exportar con exports (forma alternativa)

También puedes usar exports directamente:

// archivo: utilidades.js
exports.multiplicar = function(a, b) {
  return a * b;
};

exports.dividir = function(a, b) {
  return b !== 0 ? a / b : 'Error: división por cero';
};

// En otro archivo
const utilidades = require('./utilidades');
console.log(utilidades.multiplicar(4, 5)); // 20

💡 Diferencia importante:

  • module.exports = algo - Reemplaza completamente lo que se exporta
  • exports.propiedad = valor - Agrega propiedades al objeto exportado
  • No puedes hacer exports = algo (no funcionará)

Ejemplo práctico completo

Vamos a crear un ejemplo paso a paso:

// archivo: persona.js
function Persona(nombre, edad) {
  this.nombre = nombre;
  this.edad = edad;
}

Persona.prototype.saludar = function() {
  return `Hola, soy ${this.nombre} y tengo ${this.edad} años`;
};

module.exports = Persona;
// archivo: app.js
const Persona = require('./persona');

const juan = new Persona('Juan', 25);
console.log(juan.saludar()); // "Hola, soy Juan y tengo 25 años"

⚙️ Módulos Nativos de Node.js

Node.js viene con muchos módulos incorporados que proporcionan funcionalidades útiles. No necesitas instalarlos, solo importarlos.

Módulo fs (File System)

Permite trabajar con el sistema de archivos (leer, escribir, crear archivos y carpetas):

const fs = require('fs');

// Leer un archivo de forma síncrona (bloquea hasta terminar)
const contenido = fs.readFileSync('archivo.txt', 'utf8');
console.log(contenido);

// Leer un archivo de forma asíncrona (no bloquea)
fs.readFile('archivo.txt', 'utf8', (error, datos) => {
  if (error) {
    console.error('Error al leer:', error);
    return;
  }
  console.log(datos);
});

// Escribir en un archivo
fs.writeFileSync('nuevo-archivo.txt', 'Contenido del archivo');

// Verificar si un archivo existe
if (fs.existsSync('archivo.txt')) {
  console.log('El archivo existe');
}

Módulo path

Proporciona utilidades para trabajar con rutas de archivos y directorios:

const path = require('path');

// Unir rutas (funciona en cualquier sistema operativo)
const rutaCompleta = path.join(__dirname, 'carpeta', 'archivo.txt');
console.log(rutaCompleta);
// En Linux/Mac: /ruta/al/proyecto/carpeta/archivo.txt
// En Windows: C:\ruta\al\proyecto\carpeta\archivo.txt

// Obtener la extensión de un archivo
const extension = path.extname('documento.pdf');
console.log(extension); // '.pdf'

// Obtener el nombre del archivo
const nombreArchivo = path.basename('/ruta/al/archivo.txt');
console.log(nombreArchivo); // 'archivo.txt'

// Obtener el directorio
const directorio = path.dirname('/ruta/al/archivo.txt');
console.log(directorio); // '/ruta/al'

// __dirname - Variable global con la ruta del directorio actual
console.log(__dirname); // Ruta donde está el archivo actual

Módulo os

Proporciona información sobre el sistema operativo:

const os = require('os');

console.log(os.platform());    // 'linux', 'win32', 'darwin' (Mac)
console.log(os.arch());        // 'x64', 'arm', etc.
console.log(os.hostname());    // Nombre del equipo
console.log(os.totalmem());    // Memoria total en bytes
console.log(os.freemem());     // Memoria libre en bytes
console.log(os.cpus());        // Información de los CPUs
console.log(os.homedir());     // Directorio home del usuario

Módulo http (básico)

Permite crear servidores HTTP. Aquí un ejemplo básico:

const http = require('http');

// Crear un servidor básico
const servidor = http.createServer((req, res) => {
  // Configurar la respuesta
  res.writeHead(200, { 'Content-Type': 'text/html; charset=utf-8' });
  res.end('<h1>¡Hola desde Node.js!</h1>');
});

// Escuchar en el puerto 3000
servidor.listen(3000, () => {
  console.log('Servidor corriendo en http://localhost:3000');
});

// Para detener el servidor: Ctrl + C

Nota: En la siguiente clase usaremos Express.js, que es más fácil y potente que el módulo http básico.

✨ ES6 Modules - El Estándar Moderno

ES6 Modules es el estándar moderno de JavaScript. Aunque CommonJS es más común en Node.js, ES6 Modules es el futuro y se usa cada vez más.

Configurar ES6 Modules

Para usar ES6 Modules en Node.js, necesitas agregar "type": "module" en tu package.json: 

// package.json
{
  "name": "mi-proyecto",
  "version": "1.0.0",
  "type": "module",  // ← Esto habilita ES6 Modules
  "main": "index.js"
}

Exportar con export

// archivo: calculadora.js

// Exportación nombrada (puedes exportar múltiples cosas)
export function sumar(a, b) {
  return a + b;
}

export function restar(a, b) {
  return a - b;
}

// O exportar al final
function multiplicar(a, b) {
  return a * b;
}

export { multiplicar };

// Exportación por defecto (solo una por módulo)
export default function dividir(a, b) {
  return a / b;
}

Importar con import

// archivo: app.js

// Importar exportaciones nombradas
import { sumar, restar } from './calculadora.js';
console.log(sumar(5, 3)); // 8

// Importar con alias
import { sumar as add, restar as subtract } from './calculadora.js';

// Importar todo como un objeto
import * as calc from './calculadora.js';
console.log(calc.sumar(5, 3));

// Importar exportación por defecto
import dividir from './calculadora.js';
console.log(dividir(10, 2)); // 5

// Importar ambas (nombrada y por defecto)
import dividir, { sumar, restar } from './calculadora.js';

⚠️ Importante: En ES6 Modules, las extensiones de archivo (.js) son obligatorias en las rutas de importación. En CommonJS no son necesarias.

Comparación: CommonJS vs ES6 Modules

Aspecto CommonJS ES6 Modules
Sintaxis require() / module.exports import / export
Carga Síncrona (en tiempo de ejecución) Asíncrona (en tiempo de compilación)
Extensiones Opcionales en rutas Obligatorias (.js, .mjs)
Configuración Por defecto en Node.js Requiere "type": "module"
Uso Muy común en Node.js Estándar moderno, creciendo

Vamos a crear un proyecto pequeño que demuestre el uso de módulos en la práctica.

Estructura del proyecto

mi-proyecto/
├── package.json
├── index.js          (archivo principal)
├── utils/
│   ├── calculadora.js
│   ├── validaciones.js

Paso 1: Crear módulo de utilidades

// utils/calculadora.js
function sumar(a, b) {
  return a + b;
}

function restar(a, b) {
  return a - b;
}

function multiplicar(a, b) {
  return a * b;
}

module.exports = {
  sumar,
  restar,
  multiplicar
};

Paso 2: Crear módulo de validaciones

// utils/validaciones.js
function esEmailValido(email) {
  return email.includes('@') && email.includes('.');
}

function esMayorDeEdad(edad) {
  return edad >= 18;
}

module.exports = {
  esEmailValido,
  esMayorDeEdad
};

Paso 3: Crear módulo para trabajar con archivos

// utils/archivos.js
const fs = require('fs');
const path = require('path');

function leerArchivo(nombreArchivo) {
  const ruta = path.join(__dirname, '..', 'datos', nombreArchivo);
  try {
    const contenido = fs.readFileSync(ruta, 'utf8');
    return JSON.parse(contenido);
  } catch (error) {
    console.error('Error al leer archivo:', error.message);
    return null;
  }
}

function escribirArchivo(nombreArchivo, datos) {
  const ruta = path.join(__dirname, '..', 'datos', nombreArchivo);
  try {
    fs.writeFileSync(ruta, JSON.stringify(datos, null, 2));
    return true;
  } catch (error) {
    console.error('Error al escribir archivo:', error.message);
    return false;
  }
}

module.exports = {
  leerArchivo,
  escribirArchivo
};

Paso 4: Crear archivo de datos

// datos/usuarios.json
[
  {
    "nombre": "Juan",
    "edad": 25,
    "email": "juan@example.com"
  },
  {
    "nombre": "María",
    "edad": 30,
    "email": "maria@example.com"
  }
]

Paso 5: Usar los módulos en el archivo principal

// index.js
const calculadora = require('./utils/calculadora');
const validaciones = require('./utils/validaciones');
const archivos = require('./utils/archivos');

// Usar el módulo de calculadora
console.log('Suma:', calculadora.sumar(10, 5));
console.log('Resta:', calculadora.restar(10, 5));
console.log('Multiplicación:', calculadora.multiplicar(10, 5));

// Usar el módulo de validaciones
const email = 'usuario@example.com';
console.log('Email válido:', validaciones.esEmailValido(email));
console.log('Mayor de edad:', validaciones.esMayorDeEdad(20));

// Usar el módulo de archivos
const usuarios = archivos.leerArchivo('usuarios.json');
if (usuarios) {
  console.log('Usuarios cargados:', usuarios);
  
  // Agregar un nuevo usuario
  usuarios.push({
    nombre: 'Pedro',
    edad: 28,
    email: 'pedro@example.com'
  });
  
  // Guardar los cambios
  archivos.escribirArchivo('usuarios.json', usuarios);
  console.log('Usuario agregado exitosamente');
}

📚 Importar Módulos de Terceros (npm)

Cuando instalas un paquete con npm, puedes importarlo igual que los módulos nativos, pero sin la ruta relativa.

Ejemplo con Express

// Primero instalar: npm install express
const express = require('express');

const app = express();

app.get('/', (req, res) => {
  res.send('¡Hola desde Express!');
});

app.listen(3000, () => {
  console.log('Servidor en http://localhost:3000');
});

Ejemplo con otros paquetes comunes

// Instalar: npm install colors
const colors = require('colors');

console.log('Texto en rojo'.red);
console.log('Texto en verde'.green);
console.log('Texto en azul'.blue);

// Instalar: npm install moment
const moment = require('moment');

console.log(moment().format('YYYY-MM-DD'));
console.log(moment().format('dddd, MMMM Do YYYY'));

💡 Tip: Los módulos de npm se buscan primero en node_modules/, luego en los módulos nativos. Por eso no necesitas la ruta ./ cuando importas paquetes instalados.

✅ Buenas Prácticas con Módulos

Sigue estas recomendaciones para escribir código modular y mantenible.

1. Organización de archivos

  • Un módulo = una responsabilidad
  • Nombres descriptivos para archivos y funciones
  • Agrupa módulos relacionados en carpetas
  • Usa index.js para exportar múltiples módulos de una carpeta

2. Estructura recomendada

proyecto/
├── package.json
├── index.js              (punto de entrada)
├── config/
│   └── database.js       (configuraciones)
├── models/
│   └── usuario.js        (modelos de datos)
├── utils/
│   ├── helpers.js        (funciones auxiliares)
│   └── validaciones.js
├── routes/
│   └── api.js            (rutas)
└── controllers/
    └── usuarioController.js

3. Exportar solo lo necesario

// ❌ Mal: Exportar todo
module.exports = {
  funcion1,
  funcion2,
  variableInterna,
  constantePrivada
};

// ✅ Bien: Exportar solo la API pública
module.exports = {
  funcion1,
  funcion2
};
// Las variables internas quedan privadas

4. Usar rutas absolutas cuando sea posible

// ❌ Mal: Rutas relativas complicadas
const util = require('../../../utils/helper');

// ✅ Bien: Usar path.join o configurar rutas
const path = require('path');
const util = require(path.join(__dirname, 'utils', 'helper'));

❓ Preguntas / Mini desafío

¿Cuál es la diferencia entre module.exports y exports?

module.exports es el objeto real que se exporta. exports es una referencia a module.exports. Puedes agregar propiedades con exports.propiedad = valor, pero no puedes reasignar exports directamente. Para reemplazar completamente lo exportado, usa module.exports = algo.

¿Cuándo usar CommonJS y cuándo usar ES6 Modules?

Usa CommonJS cuando trabajes con proyectos Node.js tradicionales, la mayoría de paquetes de npm, o cuando necesites compatibilidad máxima. Usa ES6 Modules cuando quieras usar el estándar moderno, trabajar con código que también se ejecuta en el navegador, o en proyectos nuevos donde puedes elegir.

¿Qué es __dirname y para qué sirve?

__dirname es una variable global en Node.js que contiene la ruta absoluta del directorio donde está el archivo actual. Es muy útil para construir rutas relativas a la ubicación del archivo, especialmente cuando trabajas con archivos del sistema.

¿Por qué debo usar path.join() en lugar de concatenar strings para rutas?

path.join() maneja automáticamente las diferencias entre sistemas operativos (Windows usa \, Linux/Mac usa /), maneja correctamente las barras dobles, y normaliza las rutas. Esto hace que tu código sea portable entre diferentes sistemas operativos.

¿Cuál es la diferencia entre readFileSync() y readFile()?

readFileSync() es síncrono: bloquea la ejecución hasta que el archivo se lee completamente. readFile() es asíncrono: no bloquea y usa un callback. En aplicaciones que manejan múltiples peticiones, es mejor usar la versión asíncrona para no bloquear el servidor.

Desafío - Sistema de Gestión de Heladería Modular: Crea un proyecto para gestionar los sabores de helado de una heladería con la siguiente estructura:

  1. Crea la estructura de carpetas:
    • heladeria/ - carpeta principal
    • heladeria/modulos/ - para tus módulos
    • heladeria/datos/ - para archivos JSON
  2. Crea el módulo modulos/sabor.js:
    • Función crearSabor(id, nombre, precio, disponible) que retorna un objeto sabor de helado
    • Función marcarDisponible(sabor) que marca un sabor como disponible
    • Función marcarAgotado(sabor) que marca un sabor como agotado
    • Exporta todas las funciones
  3. Crea el módulo modulos/gestor.js:
    • Función agregarSabor(inventario, sabor) - agrega un sabor al inventario
    • Función obtenerSaboresDisponibles(inventario) - filtra sabores disponibles
    • Función buscarSaborPorNombre(inventario, nombre) - busca un sabor por nombre
    • Función calcularTotalInventario(inventario) - suma el precio de todos los sabores
    • Exporta todas las funciones
  4. Crea el módulo modulos/archivos.js:
    • Función guardarInventario(inventario) - guarda en datos/inventario.json
    • Función cargarInventario() - carga desde datos/inventario.json
    • Usa fs y path de Node.js
    • Exporta ambas funciones
  5. Crea index.js en la raíz:
    • Importa todos los módulos que creaste
    • Crea al menos 5 sabores de helado de ejemplo (ej: "Vainilla", "Chocolate", "Fresa", etc.)

    • Muestra el total del inventario
    • Busca un sabor por nombre y muestra su información
  6. Ejecuta el proyecto: node index.js

💡 Tip: Usa CommonJS (require/module.exports). Organiza bien tu código en módulos. Usa path.join(__dirname, ...) para las rutas de archivos. Cada sabor debe tener: id, nombre, precio (número), y disponible (boolean).
