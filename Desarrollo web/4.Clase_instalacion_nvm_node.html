Clase: Instalación y Configuración de Node.js

Material de apoyo para estudiantes — desarrollo web.

Objetivo

Instalar y configurar Node.js en tu computadora usando nvm (Node Version Manager), crear tu primer proyecto Node.js, y entender cómo ejecutar JavaScript fuera del navegador.

🚀 ¿Qué es Node.js?

Node.js es un entorno de ejecución de JavaScript construido sobre el motor V8 de Chrome. Permite ejecutar JavaScript en el servidor, fuera del navegador.

Características principales

  • JavaScript en el servidor: Ejecuta JavaScript fuera del navegador
  • Asíncrono y no bloqueante: Maneja múltiples operaciones simultáneamente
  • Basado en eventos: Usa un modelo de programación orientado a eventos
  • Ecosistema enorme: npm (Node Package Manager) tiene millones de paquetes
  • Ideal para APIs y servidores: Perfecto para desarrollo backend

¿Para qué se usa Node.js?

  • Crear servidores web y APIs RESTful
  • Desarrollar aplicaciones backend
  • Herramientas de línea de comandos
  • Aplicaciones de tiempo real (chat, juegos)
  • Microservicios
  • Scripts de automatización

📦 ¿Qué es nvm (Node Version Manager)?

nvm es una herramienta que permite instalar y gestionar múltiples versiones de Node.js en tu computadora. Es muy útil porque diferentes proyectos pueden requerir diferentes versiones de Node.js.

Ventajas de usar nvm

  • Múltiples versiones: Puedes tener varias versiones de Node.js instaladas
  • Cambio fácil: Cambiar entre versiones es muy simple
  • Sin conflictos: Cada proyecto puede usar su versión específica
  • Actualizaciones: Fácil de actualizar a nuevas versiones
  • Recomendado: Es la forma recomendada de instalar Node.js

🐧 Instalación en Linux

Sigue estos pasos para instalar nvm y Node.js en sistemas Linux (Ubuntu, Debian, etc.)

Paso 1: Instalar nvm

Abre tu terminal y ejecuta:

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

O si prefieres usar wget:

wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

Paso 2: Recargar la configuración

Después de instalar, recarga tu configuración de shell:

source ~/.bashrc

O si usas zsh:

source ~/.zshrc

Paso 3: Verificar la instalación

Verifica que nvm se instaló correctamente:

nvm --version

Deberías ver un número de versión (ej: 0.40.3)

Paso 4: Instalar la última versión estable de Node.js

Instala la última versión LTS (Long Term Support) de Node.js:

nvm install --lts

O instala la última versión disponible:

nvm install node

Paso 5: Usar la versión instalada

Activa la versión que acabas de instalar:

nvm use --lts

O para usar la última versión:

nvm use node

Paso 6: Configurar como versión por defecto (opcional)

Para que esta versión se use automáticamente:

nvm alias default node

O si instalaste LTS:

nvm alias default lts/*

Paso 7: Verificar Node.js y npm

Verifica que Node.js y npm se instalaron correctamente:

node --version
npm --version

Deberías ver las versiones instaladas. Ejemplo:

v20.11.0
10.2.4

🍎 Instalación en macOS

Los pasos son muy similares a Linux. Puedes usar el mismo método o Homebrew.

Método 1: Usando el script de instalación (Recomendado)

Es exactamente igual que en Linux:

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
source ~/.zshrc # macOS usa zsh por defecto
nvm install --lts
nvm use --lts
nvm alias default lts/*

Método 2: Usando Homebrew (Alternativo)

Si prefieres usar Homebrew:

brew install nvm
mkdir ~/.nvm
# Agregar a ~/.zshrc:
export NVM_DIR="$HOME/.nvm"
[ -s "/opt/homebrew/opt/nvm/nvm.sh" ] && \. "/opt/homebrew/opt/nvm/nvm.sh"
source ~/.zshrc
nvm install --lts
nvm use --lts

🪟 Instalación en Windows

En Windows, usamos nvm-windows, que es una versión adaptada para Windows.

Paso 1: Descargar nvm-windows

  1. Ve a: https://github.com/coreybutler/nvm-windows/releases
  2. Descarga el archivo nvm-setup.exe de la última versión
  3. Ejecuta el instalador y sigue las instrucciones

Paso 2: Abrir PowerShell o CMD como Administrador

Es importante abrir la terminal como administrador para evitar problemas de permisos.

Paso 3: Instalar Node.js

nvm install lts
nvm use lts
nvm alias default lts

Paso 4: Verificar la instalación

node --version
npm --version

⚙️ Comandos Útiles de nvm

Estos son los comandos más comunes que usarás con nvm.

Comando Descripción
nvm --version Ver la versión de nvm instalada
nvm list Listar todas las versiones de Node.js instaladas
nvm list available Listar todas las versiones disponibles para instalar
nvm install <version> Instalar una versión específica (ej: nvm install 20.11.0)
nvm install --lts Instalar la última versión LTS
nvm install node Instalar la última versión disponible
nvm use <version> Cambiar a una versión específica
nvm use --lts Usar la última versión LTS
nvm current Ver la versión actualmente en uso
nvm alias default <version> Establecer una versión como predeterminada
nvm uninstall <version> Desinstalar una versión específica

📁 Crear tu Primer Proyecto Node.js

Ahora vamos a crear tu primer proyecto Node.js y ejecutar código JavaScript en el servidor.

Paso 1: Crear un directorio para tu proyecto

mkdir mi-primer-proyecto
cd mi-primer-proyecto

Paso 2: Inicializar un proyecto Node.js

Crea un archivo package.json que describe tu proyecto:

npm init -y

El flag -y acepta todas las opciones por defecto. Esto creará un archivo package.json.

Paso 3: Crear tu primer archivo JavaScript

Crea un archivo llamado index.js:

// index.js
console.log("¡Hola desde Node.js!");

// Variables y funciones funcionan igual que en el navegador
let nombre = "Estudiante";
let edad = 20;

function saludar(nombre, edad) {
return `Hola, ${nombre}. Tienes ${edad} años.`;
}

console.log(saludar(nombre, edad));

// Usar módulos de Node.js
const os = require('os');
console.log(`Sistema operativo: ${os.platform()}`);
console.log(`Arquitectura: ${os.arch()}`);

Paso 4: Ejecutar tu código

Ejecuta el archivo usando Node.js:

node index.js

Deberías ver la salida en la terminal:

¡Hola desde Node.js!
Hola, Estudiante. Tienes 20 años.
Sistema operativo: linux
Arquitectura: x64

📄 Entendiendo package.json

El archivo package.json es el corazón de cualquier proyecto Node.js. Contiene información sobre tu proyecto y sus dependencias.

Estructura básica

{
"name": "mi-primer-proyecto",
"version": "1.0.0",
"description": "",
"main": "index.js",
"scripts": {
"test": "echo \"Error: no test specified\" && exit 1"
},
"keywords": [],
"author": "",
"license": "ISC"
}

Campos importantes

  • name: Nombre de tu proyecto (sin espacios, minúsculas)
  • version: Versión de tu proyecto (sigue semver: major.minor.patch)
  • description: Descripción breve del proyecto
  • main: Archivo principal que se ejecuta (por defecto: index.js)
  • scripts: Comandos que puedes ejecutar con npm run
  • dependencies: Paquetes que tu proyecto necesita para funcionar
  • devDependencies: Paquetes solo necesarios durante el desarrollo

Agregar scripts personalizados

Puedes agregar scripts útiles en package.json:

{
"scripts": {
"start": "node index.js",
"dev": "node index.js",
"test": "echo \"Error: no test specified\" && exit 1"
}
}

Luego ejecuta:

npm start
# o
npm run dev

📦 npm (Node Package Manager) - Conceptos Básicos

npm viene incluido con Node.js y es el gestor de paquetes más grande del mundo. Te permite instalar y gestionar librerías de JavaScript.

Comandos básicos de npm

Comando Descripción
npm --version Ver la versión de npm
npm init Crear un nuevo package.json interactivamente
npm init -y Crear package.json con valores por defecto
npm install <paquete> Instalar un paquete (ej: npm install express)
npm install <paquete> --save-dev Instalar como dependencia de desarrollo
npm install Instalar todas las dependencias del package.json
npm list Listar paquetes instalados
npm uninstall <paquete> Desinstalar un paquete
npm update Actualizar todos los paquetes

Ejemplo: Instalar un paquete

# Instalar Express (framework web)
npm install express

# Esto creará:
# - node_modules/ (carpeta con el paquete y sus dependencias)
# - package-lock.json (archivo que bloquea las versiones)
# - Actualizará package.json con la dependencia

🌐 Diferencias: Node.js vs Navegador

Aunque es el mismo lenguaje, hay diferencias importantes entre ejecutar JavaScript en Node.js y en el navegador.

Aspecto Navegador Node.js
DOM ✅ Disponible (document, window) ❌ No disponible
Módulos ES6 modules (import/export) CommonJS (require/module.exports) o ES6
Variables globales window, document global, process
File System ❌ No disponible ✅ Disponible (fs module)
HTTP requests fetch, XMLHttpRequest http, https modules, fetch (v18+)
Ejecución En el navegador del usuario En el servidor

Asegúrate de que todo esté instalado correctamente ejecutando estos comandos: 

# Verificar nvm
nvm --version

node --version

# Verificar npm
npm --version

nvm current

nvm list

  • En Windows, ejecutar la terminal como administrador
